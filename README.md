# BCarplay

A browser-based, CarPlay-style music player interface.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Open%20Site-brightgreen?style=for-the-badge)](https://clinquant-macaron-63452c.netlify.app/)

## What it does

- Shows a car-dashboard-style player screen with a status bar
- Displays the current track, with a "Nothing playing" state when idle
- Includes play controls and a progress bar with elapsed and total time

## What it can do

- Queue tracks and play them back
- Track playback progress in real time
- Run in any modern browser, including on phones and in-car displays

## Usage

Open the live demo link above, or open `index.html` locally in your browser.
